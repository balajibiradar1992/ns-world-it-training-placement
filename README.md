# NS World IT Training & Placement

React + Vite responsive website using the supplied NS World logo.

## Run

```bash
npm install
npm run dev
```

Open:

http://localhost:5173

## Functional links

- Navbar sections scroll to real sections.
- Courses -> each course opens a detail modal.
- Know More -> course detail modal.
- Join Now -> enquiry section.
- Career Roadmaps -> roadmap cards show guidance.
- Talk to Placement Team -> enquiry section.
- Call Us -> phone dialer.
- WhatsApp buttons -> WhatsApp with a pre-filled message.
- Enquire Now -> enquiry form.
- Enquiry form -> opens WhatsApp with form details.
- Contact -> contact section.
- Login / Register -> enquiry section for registration.
- Footer links are functional.
